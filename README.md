## Technical Assessment for Platinum Outsourcing

This serves as my submission for my technical assessment for Platinum Outsourcing.

### Tech

- [Vite](https://vite.dev/)
- [React](https://react.dev)
- Typescript
- [TailwindCSS](https://tailwindcss.com)
- [shadcn](https://ui.shadcn.com/) - used for UI components
- [Tanstack Router](https://tanstack.com/router) - used for file-based routing
- [Tanstack Query](https://tanstack.com/query/latest) - used for mock data fetching
- [Biome](https://biomejs.dev) - linter and formatter

### Setup

- Install dependencies
```
pnpm i
```

- Run the application
```
pnpm dev
```

- Navigate to `/settings/integrations` to view the integrations page
